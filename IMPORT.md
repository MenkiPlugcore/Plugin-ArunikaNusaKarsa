# ARUNIKA — Nusa Karsa

Repository import target: v0.1.0 through v1.0.4 (preview), Paper 1.21.11 / Java 21.

The historical import is distributed as a Git bundle and checkout ZIP. This initialization file is not the plugin source or a release binary. After importing the bundle, `main` will contain the v1.0.4 source, historical tags, original release packages, Java ItemsAdder models, Bedrock Geyser packs/mappings and installation instructions.

Do not install preview JARs on a production server without testing Paper, Vault, Geyser/Floodgate and backing up the WTB ledger. Keep only one Nusa Karsa JAR installed, and do not run standalone ArunikaWTB alongside the embedded module.
